# Code of Conduct

## Our standards

Keep discussions about the project. Be direct. Argue about the code or the design, not about who wrote it.

## Unacceptable

- Personal insults, harassment, doxxing, leaking others' personal information.
- Impersonating the author or maintainers.
- Trolling, provocation, spam, self-promotion, advertising.
- Flooding, off-topic posts, and language that derails the thread.
- Posting in any language other than English. Project spaces are English-only.

## AI-generated content in discussions

When you reply in an issue, discussion, or PR comment, you are talking to a human. That person deserves to know whether they are reading your words or a model's.

- **Disclosure is mandatory.** Any comment that contains AI-generated text must start with `[ai]` and the body of the comment must be inside a Markdown quote block (`>`). The first non-quoted line must briefly state what you asked the model to do (for example: `> Summarize the discussion so far`).
- **AI replies must follow a human reply in the same thread.** AI is for follow-ups, clarifications, and rewording — not for opening a conversation with another human. The first reply in any thread must be yours.
- **Issues and PR descriptions are documents, not conversations.** AI can help you investigate and shape the text, but the bar is "did you read it and agree with it". A useful issue describes what you observed, what you tried, and what you expected. A useful PR description explains the change, the motivation, and how to test it. Whether you wrote that prose yourself or with help is fine, as long as you stand behind every word.
- **You remain responsible for the content.** A model can be wrong, confident, and rude in ways you would not be. Read what you post, agree with it, and stand behind it.

## Where this applies

GitHub issues, pull requests, and discussions. Anywhere else the project opens later.

## Reporting

Contact the author through [orchidfiles.com](https://orchidfiles.com). The author reviews each report and decides what to do. There is no formal escalation — common sense applies.
